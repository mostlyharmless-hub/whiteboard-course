# M5 TTS 配音与视频导出 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把「AIGC职业规划实战」的讲解稿用阿里云 Qwen3-TTS（男声 Ethan）合成配音，按**原课程时间轴**（7:00）拼成 mp3；再把播放器的板书按帧渲染、与配音合成 mp4 视频课。

**Architecture:**
- TTS：逐段合成（DashScope `qwen3-tts-flash`，文本先按术语表纠错），每段音频放在原 `begin_time`，段间静音；某段比可用窗口长时用 ffmpeg `atempo` 加速（≤ 2×）。写出 mp3 与 `<name>.tts.transcript.json`（时间不变、文本纠错后）。
- 视频：播放器状态是 `t` 的纯函数，所以用 Playwright 在 `?render=1` 模式下逐帧 `setTime(i / fps)` 截图，通过管道喂给 ffmpeg（libx264 + aac）与 mp3 合成 mp4，画面与音频严格对齐。渲染模式隐藏界面、相机瞬移、等待字体与 Mermaid 就绪。
- 字幕：播放器支持 `?subtitles=<transcript.json>` 用纠错后的文本覆盖字幕显示，板书脚本无需重生成。

**Tech Stack:** Node 26 内置 fetch、ffmpeg/ffprobe（brew）、@playwright/test 1.61 的 chromium、vite dev server（子进程）。

**Spec:** CLAUDE.md（本计划是 v1 范围之外的扩展，见 ADR 004）。

## Global Constraints

- 不改 BoardScript 契约；不改生成器。
- TTS 配置在 `.env`：`TTS_BASE_URL`（DashScope `…/api/v1`）、`TTS_MODEL`（默认 `qwen3-tts-flash`）、`TTS_VOICE`（默认 `Ethan`）、`TTS_API_KEY`（缺省复用 `LLM_API_KEY`）。
- 每段合成结果按文本 + 模型 + 音色哈希缓存在 `out/tts-cache/`，重跑不再付费。
- ffmpeg 通过子进程调用，不引入 npm 音频库。
