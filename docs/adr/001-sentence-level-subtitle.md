# ADR 001：字幕显示当前句子而非整段

- 日期：2026-09-15
- 状态：已采纳
- 影响：CLAUDE.md 7.7；`src/shared/lookup.ts` 的 `sentenceAt`；播放器 `Subtitle`

## 背景

规格原文"字幕显示当前段落文本"。样例讲解稿的 ASR 段落长达 100–200 字（最长一段 216 字），按 20px 字号渲染后字幕框占满画布下半部分，遮住板书，与"板书为主、字幕为辅"的定位冲突。

## 决定

字幕显示**当前句子**：在当前段落内按句末标点（。！？；）切句，用与生成器锚点换算相同的"字符位置线性插值"规则定位 t 所在的句子。字号降到 17px、宽度 ≤ 86%。

## 影响

- 字幕与板书动作使用同一套时间模型，观感上"老师说到哪句、板书写到哪"是一致的。
- 段落内部没有更细的时间戳，句子切换时刻是估算值，长句和停顿会带来 1–2 秒偏差；这是 ASR 输入的固有限制，不在播放器侧补偿。
- 契约（BoardScript）不变，`paragraphs` 仍原样透传。
