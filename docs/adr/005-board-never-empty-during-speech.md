# ADR 005：有语音时白板不为空——翻页提前进入静默、首卡随翻页落笔

- 日期：2026-09-15
- 状态：已采纳
- 影响：CLAUDE.md 6.4；`src/generator/timeline.ts`（流水线在装配后自动套用）；`pnpm timeline` 可对已有脚本套用；报告新增"有语音但白板为空"指标

## 背景

用户要求：只要有语音，白板上必须有字；字可以比语音早出现、比语音晚消失。原时间规则（LEAD_MS = 300，`at ≥ 段落 begin_time`）下有两类空板：课程开头（第一张卡锚在段中，10.08–16.6 s 只有声音）、每次翻页后（新页开出到第一张卡之间，最长 8 秒）。

## 决定

装配后增加时间轴后处理 `ensureBoardNotEmpty`：

1. `new_page` 若锚在某段开头（`at ≤ begin_time`），允许提前进入前面的静默：`at = max(上一段 end_time, begin_time − 2000, 前一动作 at)`。锚在段中间的翻页不提前（不打断上一句）。
2. 翻页之后、第一张卡片之前的动作（`new_column` 与该卡片）全部提前到 `new_page` 时刻——新页一开就有字在写。
3. 卡片的 `reveal_ms` 不重算（提前后仍满足 `at + reveal_ms ≤ 段落 end_time`）。
4. 视频渲染默认在课程结束后多停 2 秒（`--tail`），板书晚于语音消失。

这是对 6.4 "at 不早于本段开始" 的有意放宽，只对翻页及其首卡生效。

## 影响

- 报告指标"有语音但白板为空"应为 0；样例 v2 脚本修正后为 0。
- 播放器无改动：`?t=8080` 即可看到语音前 2 秒写出的标题卡。
- 更根本的做法是让 LLM 把每页第一张卡锚到该页话题的第一句——提示词已有此倾向，后处理是兜底。
